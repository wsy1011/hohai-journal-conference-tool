# 多学科、多年份期刊目录检索设计

## 目标

在现有河海大学期刊目录网站中加入 2022、2024、2026 三个年份的自然科学、计算机专项和人文社科目录，并在首次进入网站时先让用户选择检索学科类型。三类目录使用同一套检索体验，但数据、年份口径、等级变化统计和页面状态相互独立。

## PDF 解析与规范化

2022 PDF 使用旧版“三高类别”表格，通常包含名称、主办单位/出版社和 A/B/C 类，但不提供 CN/ISSN。2024、2026 PDF 使用名称、CN/ISSN 和 A+/A/B/C 等级。

解析后统一保存以下字段：

- 稳定 ID：优先使用 CN/ISSN，否则使用规范化名称
- 名称和其他名称
- 条目类型：`期刊`、`会议` 或 `其他`
- CN/ISSN；原目录缺失时显示 `\`
- 主办单位/出版社；仅在原目录提供时保存
- 2022、2024、2026 等级
- 各年份来源页码，保留在数据中但不在详情页展示
- 与用户研究方向相关的主题标签
- 等级变化状态和方向

条目合并优先按 CN/ISSN，缺失编号时按规范化名称。同一个 CN/ISSN 下，中文刊名与西文刊名的条目分开建记录，各自取自己那一行的等级（例如 2024 年目录里 `Chinese Chemical Letters` 为 A、`中国化学快报（英文版）` 为 C，两条记录分开展示）；同一刊名的写法差异（大小写、标点、`The` 等）仍合并为一条。若某一年目录只列出其中一种刊名，该等级同步给同 CN/ISSN 的另一条记录，避免同一本刊在某一列出现空白。名称无法可靠匹配时保留为独立条目，不进行模糊猜测合并。2022 的类型通过名称中的 Conference、Symposium、Workshop、会议、大会等明确标识判断；无法可靠判断的政策报告、转载、报纸理论版等奖励成果归入 `其他`，不会调用 EasyScholar。

生成数据后必须核对：每份 PDF 中解析出的序号数量、生成条目数量、等级数量、重复 ID、空名称和失败记录。失败记录单独输出供人工复核，不静默丢弃。

## 首页学科选择

网站首次打开时显示独立选择页：

- 主标题：`请选择你要检索的学科类型`
- 选项：`计算机专项`、`自然科学`、`人文社科`
- 每个选项显示覆盖年份、条目数量和一句口径说明
- 视觉延续现有克制的黑白 OpenAI 风格，使用大面积留白、细边框和轻微悬停反馈

点击选项后进入对应检索界面。选择写入 URL hash，例如 `#discipline=natural`，因此刷新和分享链接后仍进入同一类别。没有学科参数时显示选择页，不自动记忆并跳过选择，以保证每次从根地址进入都能看到入口。

## 检索页面

三类目录复用现有搜索、类型筛选、等级筛选、状态筛选、分页、研究方向快捷筛选和详情抽屉。页面顶部增加当前学科名称和“切换学科”入口。

表格结构按当前学科动态显示：

- 名称
- CN/ISSN
- 三个年份等级列
- 状态
- 研究相关性

等级状态以当前学科的三个年份序列计算：

- 任意相邻年份等级改变：`等级变化`
- 只在后续年份出现：`新增`
- 在后续年份消失：`未收录`
- 多套适用口径不同时，在计算机专项中明确显示口径说明

详情抽屉显示三年等级、目录状态、其他名称、主办单位/出版社、研究方向标签和“期刊信息”。只有类型为 `期刊` 的条目调用 EasyScholar；会议和其他成果不调用。

## 数据与组件边界

- `public/data/catalog-natural.json`：自然科学合并目录
- `public/data/catalog-computer.json`：计算机专项合并目录
- `public/data/catalog-social.json`：人文社科合并目录
- `public/data/catalog-manifest.json`：三类目录名称、年份标签、条目数量和口径说明
- `scripts/build-multi-catalog.mjs`：解析已提取文本、规范化、合并并生成数据
- `scripts/check-catalog.mjs`：校验三套数据库及清单的一致性
- `src/components/DisciplineChooser.tsx`：首次进入的学科选择页
- `src/data/catalog.ts`：统一数据类型及按学科加载逻辑
- 现有搜索表格和详情组件：根据 manifest 动态显示列名和说明

## 错误处理

- 单个 PDF 解析失败时构建脚本失败，并指出文件和失败序号
- 某条数据缺少 CN/ISSN 时显示 `\`，不伪造编号
- 学科数据文件加载失败时显示对应学科的加载错误，并提供返回学科选择页的入口
- EasyScholar 不可用时不影响目录检索
- URL 中出现未知学科值时回到学科选择页

## 验证标准

1. 根地址打开时首先显示三个学科选择按钮。
2. 三个按钮分别进入独立数据库，刷新后保持当前类别。
3. 自然科学、人文社科显示 2022/2024/2026 三列。
4. 计算机专项显示 2022 专项、2024 自然科学综合目录、2026 专项三列，并显示口径提示。
5. 每套数据库支持名称、别名、CN/ISSN 搜索和现有筛选功能。
6. 所有成功解析的原目录条目都能展示；失败条目有可审计报告。
7. 只有期刊条目可打开 EasyScholar 期刊信息。
8. 桌面端和移动端均可完成选择、切换、搜索和查看详情。
9. `npm run data:check` 和 `npm run build` 均通过。
10. GitHub Pages 子路径部署仍可正常加载三套 JSON 数据。
